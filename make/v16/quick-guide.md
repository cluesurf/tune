# Quick guide

The sounds, the shapes, the two cluster lists, what keeps two roots
apart, and every joiner case with a worked example.

**This describes a CANDIDATE, not what `v16` builds today.** The live
build is 27 starts, 44 codas, one `l` breaker and no diphthongs. What
is below is the 18 by 26 design with the per pair joiner, measured but
not adopted. `readme.md` beside this file is the built language.

Every example is a real pair from the built pool, spelled by the same
code the measurements run on. None is invented. Generated by
`deck/tune/tmp/probe-examples.ts`.

## Sounds

```
vowels        i  e  a  o  u
diphthongs    ai  au
consonants    m  n  q  b  d  g  p  t  k  h  s  z  f  v  x  j  c  C  y  l  w  r
```

```
IPA   m n ŋ b d ɡ p t k h s z f v ʃ ʒ θ ð j l w r      aɪ aʊ
```

Seven letters hold a different symbol: `q` is ŋ, `x` is ʃ, `j` is ʒ,
`c` is θ, `C` is ð, `y` is IPA j, `g` is ɡ.

## Shapes

One syllable. `V` is a plain vowel, `D` a diphthong.

```
CVC     CVCC    CCVC    CCVCC
CDC     CDCC    CCDC    CCDCC
```

## What a root may not be

```
no root begins with w                  w is reserved for a joiner
no root begins wa
at most one of x and j
at most one of c and C
no il el ir er ul ur                   except -ul word finally
no same liquid across a vowel          rar, lal refused
no medial h
nothing on the taboo list
no liquid either side of the vowel when BOTH ends are clusters
                                       blark and blalk refused
```

## Two roots apart

Two roots must be at least two steps apart, where one step is a near
sound in one position.

```
at an onset     s z    f v    x j    c C
at a coda       b d    b p    d t    g k    p t
                f v    f c    v C    c C    l r
two nuclei      never near, they must be the same one
```

**And in any word with a cluster at either end**, these four are near
at every consonant position:

```
b p     d t     g k     m n
```

`CVC` and `CDC` are exempt, which is what holds the short words.

```
nain   main     no cluster       both stand
brain  prain    cluster onset    one of them goes
snain  smain    cluster onset    one of them goes
faind  vaind    cluster coda     one of them goes
```

## The joiner, every case

### Nothing written

The two roots run straight together. This is most seams.

```
mim + nim        mimnim
```

### Two stops of one place

`s` after a voiceless left sound, `z` after a voiced one. Both sounds
stay. The pairs are `p b`, `t d`, `k g`.

```
git + dim        gitsdim          t is voiceless
dig + kim        digzkim          g is voiced
```

A doubled stop counts as the same case.

```
dig + gim        digzgim
```

It works the same after a two sound coda.

```
bisk + gim       bisksgim
```

**Except after `-st`, where it is `l`**, because `sts` cannot be heard.

```
bist + dim       bistldim
```

### A fricative voicing pair

`l` after a voiceless left sound, `r` after a voiced one, standing
before the left root's whole CODA. The right root loses its first sound
and takes `w` before its vowel.

```
mis + zik        milswik          s is voiceless, so l
miz + sim        mirzwim          z is voiced, so r
```

**The mark goes before the whole coda, not before its last sound.** For
a one sound coda those look the same. They do not for `dj` and `tx`.

```
ditx + jik       diltxwik         the l stands before tx, not inside it
```

### A doubled fricative

The sound once, then `w` before the right root's vowel.

```
mis + sim        miswim
```

### A doubled nasal

`z` between. Both sounds stay.

```
mim + mim        mimzmim
```

### A doubled liquid

`s` between. Both sounds stay.

```
mul + lim        mulslim
```

### A cluster on the right

The `w` rules need one consonant to work on, so a cluster falls back to
a plain `l` and both roots stay whole. This covers both `w` cases.

```
mis + skiq       mislskiq         doubled fricative, cluster right
miz + skiq       mizlskiq         fricative pair, cluster right
```

### A seam that could be read two ways

A plain `l`. Nothing in the sounds is wrong; the cut is what is in
doubt.

```
mim + plin       mimlplin
```

Without it, `mimplin` is also `mimp + lin`. `mp` closes a coda and `pl`
opens an onset, so the `p` belongs to either side and neither reading
writes anything of its own.

## The joiner in one table

| the seam | written | example |
| --- | --- | --- |
| anything else | nothing | `mim + nim` = `mimnim` |
| two stops, one place, voiceless left | `s` | `git + dim` = `gitsdim` |
| two stops, one place, voiced left | `z` | `dig + kim` = `digzkim` |
| the same after `-st` | `l` | `bist + dim` = `bistldim` |
| fricative pair, voiceless left | `l` before the coda, `w` before the right vowel | `mis + zik` = `milswik` |
| fricative pair, voiced left | `r` before the coda, `w` before the right vowel | `miz + sim` = `mirzwim` |
| doubled fricative | the sound once, then `w` | `mis + sim` = `miswim` |
| doubled nasal | `z` | `mim + mim` = `mimzmim` |
| doubled liquid | `s` | `mul + lim` = `mulslim` |
| any `w` case, cluster on the right | `l`, both roots whole | `mis + skiq` = `mislskiq` |
| the cut is in doubt | `l` | `mim + plin` = `mimlplin` |

## Reading it back

Three facts make a compound readable.

**No root holds a `w`**, so a `w` is always a joiner and the sound
before it is always a seam.

**No root begins or ends with a vowel**, so a vowel between two
consonants is never root material.

**A mark before a coda is an `l` or an `r`** that the coda list does
not otherwise allow there, so it can be taken back out.
