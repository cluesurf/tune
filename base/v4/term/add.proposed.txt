# A proposed ADD pass, 2026-09-16, fifth and final draft.
#
# Graded by `pnpm --dir deck/tune v4:add`. Nothing here is applied by
# running that. It reports.
#
# The criterion, after five drafts:
#
#   Add a root when it is a major irreducible natural kind, a highly
#   productive scientific primitive, or a concept whose ordinary
#   composition would be awkward or misleading. Do NOT add a root
#   merely because English or science has a lexicalized word for it.
#
# Two decisions in this draft are the ones that matter.
#
# **The elements go positional.** Roots for the few dozen a culture
# names without a laboratory, and `element + atomic number` for the
# rest. Ninety arbitrary roots for the periodic table cannot be
# justified against 1,024 short forms, and an element is already a
# coordinate.
#
# **A natural kind is not a scientific compound.** `chloroplast`
# advertises how to build it. `quartz` does not. That distinction is
# what the `compose-instead` band is for.
